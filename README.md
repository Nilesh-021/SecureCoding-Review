# CodeAlpha Secure Coding Review

## 📌 Project Overview

This project is developed for the CodeAlpha Cyber Security Internship - Task 3.

The project demonstrates a secure coding review of a Python application. The original application was manually reviewed to identify security vulnerabilities, and a secure version was developed to address the identified issues.

## 🎯 Objectives

- Review source code for security vulnerabilities.
- Identify common secure coding weaknesses.
- Understand the risks associated with insecure code.
- Implement remediation techniques.
- Compare vulnerable and secure versions of the application.

## 🛠️ Technologies Used

- Python
- SQLite
- PBKDF2-HMAC-SHA256
- Secure random salt generation
